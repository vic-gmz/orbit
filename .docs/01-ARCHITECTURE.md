# 01 — Architecture

## Stack

| Layer | Technology |
|---|---|
| Framework | React 19 + TypeScript ~6.0 |
| Bundler | Vite 8 |
| Backend / DB | Convex 1.34 (self-hosted) |
| Auth | Better Auth 1.5 + `@convex-dev/better-auth` (email/password + Google) |
| CSS | Tailwind CSS v4 (utility only, no design effort) |
| CSS Tooling | `@tailwindcss/vite` plugin (no PostCSS, no config file) |

| Charts | Recharts (Dashboard + Stats) |
| Router | React Router v7+ (hash or browser router via Convex proxy) |

## Tailwind CSS v4 Setup

```bash
npm install tailwindcss @tailwindcss/vite
```

- Add `tailwindcss()` plugin to `vite.config.ts`:
  ```ts
  import tailwindcss from "@tailwindcss/vite";

  export default defineConfig({
    plugins: [react(), tailwindcss()],
  });
  ```
- Replace `@tailwind` directives in `src/index.css` with:
  ```css
  @import "tailwindcss";
  ```
- No `tailwind.config.js` — configuration goes in CSS via `@theme`.

## Key Decisions

1. **No styling effort** — Tailwind only for structural layout (flex, grid, padding). No colors, themes, animations beyond functional necessity.
2. **Sidebar navigation** — Fixed left sidebar, content on right.
3. **In-app notifications** — Badge on sidebar for pending follow-ups. Toast for achievement unlocks.
4. **Constellation data ready** — `contacts.interactionCount` and `contacts.lastInteractionAt` are kept in sync via mutations. No additional data prep needed for v2.
5. **Self-hosted Convex** — File storage (`ctx.storage.store()`) works identically to cloud. Avatar upload uses Convex storage.
